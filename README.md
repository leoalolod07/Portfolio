# Leo Hacker Portfolio

Welcome to **Leo Alolod’s Portfolio** – a neon-themed, hacker-style personal portfolio website showcasing skills, projects, and contact information.  

This portfolio is designed with a **Matrix rain effect**, glowing neon sidebar, typing hacker animation, and a responsive layout.

---

## 🔹 Features

- **Neon Hacker Theme:** Dark background with glowing neon text and sidebar.
- **Matrix Rain Effect:** Animated matrix code on the background using `<canvas>`.
- **Typing Animation:** Hacker-style typing effect for welcome messages.
- **Profile Section:** Animated profile picture with hover effects.
- **Responsive Sidebar Navigation:** Links to About, Skills, Projects, and Contact sections.
- **Music Background:** Autoplay looping background music.
- **Animations Everywhere:** Fade-in, slide-in, bounce, glow, and pulsing animations for a dynamic feel.

---

## 🛠 Technologies Used

- **HTML5** – Structure of the website
